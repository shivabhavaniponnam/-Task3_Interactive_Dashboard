# Task 3 - Interactive Dashboard using Power BI

## Objective
Create an interactive dashboard using Power BI to analyze sales and profit data from the Superstore dataset.

## Tools Used
- Power BI
- Superstore Dataset

## Dashboard Features
- Total Sales Card
- Total Profit Card
- Average Order Value (AOV)
- Sales by Category
- Profit by Region
- Sales by Segment
- Interactive Slicers for filtering

## Insights
- Technology category generated high sales.
- Some regions showed lower profit compared to others.
- Consumer segment contributed major sales.

Built an interactive business dashboard for better data visualization and decision-making.
